# SocialPoster — تطبيق Windows 🚀

تطبيق Windows كيخليك تطلع صورة ولا فيديو مرة وحدة، وتنشرو فـ 9 منصات، دابا ولا فوقت لي بغيتي.
عندو نافذة بوحدو (ماشي فالمتصفح)، والمفاتيح كتدخلهم من صفحة **الإعدادات** داخل البرنامج.

---

## كيفاش تخرج `SocialPoster.exe` (اختار طريقة وحدة)

### الطريقة 1: من الحاسوب ديالك (الأسهل)
1. نزل **Python** من https://www.python.org/downloads/
   ⚠️ فأول شاشة ديال التنصيب، علم على **Add Python to PATH**.
2. فك الملف `SocialPoster.zip`.
3. دبل كليك على **`build.bat`** وتسنى (المرة الأولى كتاخد 3-5 دقايق).
4. غادي يتحل ليك الدوسي `dist` وفيه **`SocialPoster.exe`** ✅
   نسخو للـ Desktop ولا فين ما بغيتي. من دابا ما بقيتيش محتاج Python ولا الكود.

### الطريقة 2: بلا Python (عبر GitHub)
1. دير حساب فـ github.com ← New repository.
2. طلع فيه جميع الملفات ديال هاد الدوسي (حتى الدوسي `.github`).
3. سير لـ **Actions** ← تسنى حتى يكمل البناء (≈ 5 دقايق) ← ضغط عليه ← تحت **Artifacts** نزل `SocialPoster-windows`.

> 🛡️ Windows Defender يقدر يقول "Windows protected your PC" حيت البرنامج جديد وما موقعش.
> ضغط **More info** ← **Run anyway**. هادشي عادي فالبرامج اللي كتبنيها بيديك.

---

## الاستعمال

1. حل **SocialPoster.exe**.
2. سير لـ **الإعدادات** ← عمر Telegram ولا Discord ← **حفظ**.
3. رجع لـ **نشر** ← جر صورة/فيديو ← كتب النص ← **نشر**.
4. ملي تكون واجد، طفي **وضع التجربة** من الإعدادات باش ينشر بصح.

**النشر المبرمج:** خاص البرنامج يبقى مفتوح فالوقت ديال النشر.
فعل **"شغل البرنامج مع Windows"** فالإعدادات باش يتحل بوحدو (مصغر) ملي تشعل الحاسوب.
إلا بغيتي تسدو وعندك منشورات مبرمجة، غادي يسولك قبل.

**إلا فشلات شي منصة:** حط الماوس على السمية ديالها فالسجل باش تشوف السبب، وضغط **عاود** باش يعاود غير فيها.

## ربط المنصات

كل منصة فيها شرح صغير داخل صفحة الإعدادات. ملخص:

| المنصة | صور | فيديو | شنو خاصك |
|---|---|---|---|
| Telegram | ✅ | ✅ | بوت من @BotFather + زيدو Admin فالقناة |
| Discord | ✅ | ✅ | Webhook URL |
| Facebook Page | ✅ | ✅ | Page ID + Page Access Token |
| Instagram | ✅ | ✅ Reels | حساب Business + نفس توكن Facebook + **رابط عمومي** (شوف تحت) |
| YouTube | — | ✅ | `client_secret.json` ← ضغط «ربط YouTube» |
| TikTok | — | ✅ | Access Token (خاصين حتى توافق TikTok) |
| X | ✅ | ✅ | 4 مفاتيح (الـ API بالخلاص) |
| LinkedIn | ✅ | — | Access Token + Author URN |
| Pinterest | ✅ | — | Access Token + Board ID |

### Instagram والرابط العمومي
Instagram ما كيقبلش الملف مباشرة، خاصو يجي ياخدو من رابط. البرنامج خدام على البورت **51791**:
1. نزل **ngrok** من ngrok.com وسجل.
2. شغل: `ngrok http 51791`
3. نسخ الرابط `https://....ngrok-free.app` وحطو فـ «رابط عمومي» فالإعدادات.

## فين كيتحفظو المعلومات؟
`%APPDATA%\SocialPoster` (المفاتيح، السجل، الملفات اللي طلعتي).
كاين زر «حل الدوسي» تحت صفحة الإعدادات. ملي تحدث البرنامج، ما كيضيع والو.

## الملفات (إلا بغيتي تبدل شي حاجة)
```
desktop.py          ← كيحل النافذة (نقطة البداية)
app.py              ← النشر + الجدولة + الصفحات
config.py           ← الإعدادات وخانات كل منصة
platforms/          ← ملف لكل منصة
templates/          ← الواجهة (HTML)
build.bat           ← كيبني الـ exe
.github/workflows/  ← البناء الأوتوماتيكي فـ GitHub
```
