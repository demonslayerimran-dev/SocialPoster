SocialPoster

A personal Windows desktop app that publishes one image or video to several social platforms at once, or at a scheduled time.

What it does

  • Runs entirely on the user's own computer.
  • Uploads videos the user selects to the user's own YouTube channel through the official YouTube Data API.
  • Also publishes to other platforms the user connects (Telegram, Discord, Facebook, Instagram, TikTok, X, LinkedIn, Pinterest).
